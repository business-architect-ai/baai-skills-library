# Context afacere (comun tuturor modulelor)

Faptele durabile despre afacerea utilizatorului. Se completează o dată și se citește de toate modulele înainte de propria lor memorie, ca să nu re-întrebe bazele la fiecare rulare.

## CE VINDE
- Produs sau serviciu: [ce]
- Model de venit: [abonament / one-time / retainer / comision / altul]
- Preț mediu sau interval: [sumă]

## CLIENTUL
- Cine e clientul ideal: [descriere scurtă]
- B2B sau B2C: [care]
- Piața: [locală / națională / internațională, România implicit]

## AFACEREA
- Stadiu: [idee / pre-revenue / early / creștere / matur]
- De cât timp există: [durată]
- Echipa: [solo / câți oameni]
- Canal principal de achiziție: [care]

## OBIECTIV CURENT
- Ce urmărește acum: [creștere venit / mai mulți clienți / lansare / eficiență / altul]
- Constrângeri: [buget, timp, altele]
